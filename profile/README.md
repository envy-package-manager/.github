# envy

*what's yours... is mine.*

An unopinionated, hermetic, per-project, serverless package manager. One
`envy.lua` pins your whole toolchain, envy included, by version and checksum.
Clone the repo and run a tool.

**[Documentation](https://envy-package-manager.github.io/docs/)** &middot;
**[Latest release](https://github.com/envy-package-manager/envy/releases/latest)**

> Pre-1.0 and under active development. It works, but the CLI, the manifest
> format, and the Lua API still change between versions.
