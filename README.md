# .github

Organization-level files for [envy](https://github.com/envy-package-manager/envy).

`profile/README.md` is what renders on
<https://github.com/envy-package-manager>. Any org-wide community health files
(`CONTRIBUTING.md`, `SECURITY.md`, issue templates) would live here too, and
apply to every repo in the org that does not define its own.
